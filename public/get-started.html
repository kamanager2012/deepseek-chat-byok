常见问题（FAQ）

Q1：如何把 DeepSeek 聊天记录导入这个客户端？

先在 DeepSeek 官方导出聊天记录 .zip，然后在网页版/桌面版把文件直接拖进页面（安卓可在文件管理器中选「分享 / 用其他应用打开」），或点击「设置 → 数据管理」挑选文件；预览清单后勾选所需会话点合并导入即可，遇到同 ID 会话默认保留本机现有内容。

Q2：导入旧记录需要 API Key 吗？安全吗？

完全不需要。读取 ZIP、保留分支和浏览旧记录都在本地完成，不发外网请求。之后填 API Key 时，网页版存浏览器站点本地（因 GitHub Pages 子路径与同账号其他站点同源，敏感密钥建议改用安卓正式版 APK 或电脑便携版），Android v0.4.0+ 使用系统级 AndroidKeyStore AES-256-GCM 加密保管。

Q3：它和官方 deepseek-chat-import 插件有什么区别？

官方 deepseek-chat-import 是面向 deepseek-harness 的实验性导入插件；DeepSeek Chat BYOK 则是已经完整集成界面、独立分发、免命令行就能浏览多平台历史、管记忆卡和对接多家 BYOK API 的独立客户端。

Q4：桌面版为什么还要 Node.js 22+？

便携包使用自带的零第三方依赖 Node.js 22 服务（server.mjs）充当本地应用网关与 /_proxy，以绕过浏览器跨域限制并将所有聊天与密钥留在自己电脑。如果不想安装 Node.js，推荐使用本页面的免安装网页版或安卓 APK。
