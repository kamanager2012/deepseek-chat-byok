不知道怎么从 DeepSeek 导出旧聊天？看这 3 步

下载下来的 deepseek_data-*.zip 压缩包不需要手动解压，直接选进本工具就能导入：

在 DeepSeek 手机 App 导出
  1. 打开 DeepSeek 手机 App，点左上角边栏并点底部头像进「设置」。
  2. 点「个人资料 / 数据与隐私 → 导出数据」提交导出。
  3. 把生成的 .zip 压缩包保存到手机本地。
在 DeepSeek 电脑网页版导出
  1. 浏览器打开 chat.deepseek.com，点左下角头像进「设置」。
  2. 在「数据与隐私」里点击「导出数据」并确认。
  3. 把下载下来的 .zip 压缩包存到桌面或下载文件夹。
拿到压缩包后怎么导
  1. 不要解压 .zip，直接打开上方网页版拖进去或点击选取。
  2. 安卓手机也可在文件管理器对 .zip 点「分享 / 用其他应用打开」。
  3. 勾选想留下的聊天即可完整查看，不会覆盖原有对话。

三步导入旧聊天：实机界面展示

  1. 打开上方网页版或安卓版，点「导入旧对话（无需密钥）」。
  2. 选进刚刚下载好的官方 .zip 压缩包，勾选想留下的对话。
  3. 点确认导入后即可翻看全部原文；重要内容记到「记忆卡」，想继续聊时再接模型服务。

常见疑问

1. 这个工具和官方产品有什么关系？

这不是 DeepSeek 官方软件，也不是几个零散插件的组合方案。技术项目名为 DeepSeek Chat BYOK，是基于官方开源基础代码独立开发的完整 MIT 开源客户端。

2. 我以前从来没听过 API Key，能先用吗？

可以。导入和翻看以前导出的聊天记录、保存重要内容，都不需要填任何 API Key。只有当你希望工具帮你调用在线大模型继续往下写时，才需要在「设置 → 模型与 API」跟着指引贴入一次自己的密钥；每次回答旁边还会直接用通俗人民币估算大概花了多少元。

3. 这个免费开源项目是个人独立维护的吗？

是的。它由开源仓库 kamanager2012/deepseek-chat-byok 独立构建和公开发布；不收集你的对话，也不存在后台会员收费。

与官方 deepseek-chat-import 插件、DSH Go / DSH Community 的定位区分

项目 / 工具 定位与适用人群 关键差异
DeepSeek Chat BYOK（本项目） 独立、免费、开源的轻量聊天与历史迁移客户端 无需安装 Harness 环境，打开即用；专注 DeepSeek 旧记录搬家、保存重要设定与日常续聊。
官方 deepseek-chat-import deepseek-ai/deepseek-harness 里的实验性插件 依赖 Harness 环境运行的实验性插件（支持 CLI 与 Harness 界面），面向已经使用 Harness 工作台的开发者。
DSH Community vs DSH Go 多 Agent Terminal / Harness 工作台与远程控制端 若你需要工程级多 Agent 工具链与远程桌面审批（对应 DSH Go 赛道），见我们独立维护的兄弟仓库 kamanager2012/dsh-community。
