导入 DeepSeek 旧聊天，用自己的 API Key 继续聊

基于官方开源 chat-demo 独立扩展：连接你选择的兼容模型服务、 保存长文「记忆卡」，也能免解压导入官方导出的旧聊天。不同服务商的功能和可用性可能不同。

先把费用说明白：本客户端本身完全免费开源，不卖共享号也不加价。用自己的 API Key 对话时直接按所选服务商官方用量计费（页面会自动提示人民币估算）；仅导入和翻看官方导出的旧聊天记录完全不需要填 API Key。

方式一：免安装网页版（推荐先体验旧聊天导入）

无需安装，点「打开网页版」即可导入、查看旧聊天。如果要在线对话， 模型服务商必须支持浏览器直接连接；部分 API 会被浏览器跨域限制，填入正确的 Key 也可能无法请求。 遇到跨域报错，安卓用户请使用下方正式 APK；电脑用户可使用进阶便携版。

立即打开网页版 旧聊天导出导入教程

网页版在当前浏览器保存密钥和聊天记录，清除站点数据可能导致丢失； 在线调用时密钥会发送给你选定的模型服务商鉴权。请勿公开密钥。 iPhone / iPad 暂无独立安装包，可以先用网页版导入和查看旧聊天。

网页版存储边界：当前 GitHub Pages 页面与该 GitHub 账号下的其他 Pages 项目共享 kamanager2012.github.io 浏览器同源存储边界； 不应视为独立隔离的密钥保险库。建议只在可信设备保存 Key，重视密钥隔离的安卓用户优先使用正式签名 APK。

方式二：安卓正式版（推荐需要用 Key 聊天的安卓用户）

安卓手机可以下载安装签名 APK。它内置本地接口转发，不受浏览器跨域限制； 密钥由 Android 系统安全存储管理。你也可以在文件管理器对官方 .zip 选择「分享 / 用其他应用打开」导入旧聊天。 安装版不能保证所选模型服务商永远可用。

两步配置 API Key 开始对话

  1. 到 DeepSeek 开放平台的 API Key 页面 或你信任的兼容模型服务商申请密钥。首次使用可能需要注册和开通计费。
  2. 打开客户端 设置 → 模型与 API，选对服务商，粘贴密钥并点击 「测试并保存」。确认连接成功后再发消息； 网页版如显示跨域或 CORS 错误，可改用安卓正式版。人民币花费是参考估算，以服务商账单为准。

不知道怎么从 DeepSeek 导出旧聊天？看这 3 步

下载下来的 deepseek_data-*.zip 压缩包不需要手动解压，直接选进本工具就能导入：

在 DeepSeek 手机 App 导出
  1. 打开 DeepSeek 手机 App，点左上角边栏并点底部头像进「设置」。
  2. 点「个人资料 / 数据与隐私 → 导出数据」提交导出。
  3. 把生成的 .zip 压缩包保存到手机本地。
在 DeepSeek 电脑网页版导出
  1. 浏览器打开 chat.deepseek.com，点左下角头像进「设置」。
  2. 在「数据与隐私」里点击「导出数据」并确认。
  3. 把下载下来的 .zip 压缩包存到桌面或下载文件夹。
拿到压缩包后怎么导
  1. 不要解压 .zip，直接打开上方网页版拖进去或点击选取。
  2. 安卓手机也可在文件管理器对 .zip 点「分享 / 用其他应用打开」。
  3. 勾选想留下的聊天即可完整查看，不会覆盖原有对话。

三步导入旧聊天：实机界面展示

  1. 打开上方网页版或安卓版，点「导入旧对话（无需密钥）」。
  2. 选进刚刚下载好的官方 .zip 压缩包，勾选想留下的对话。
  3. 点确认导入后即可翻看全部原文；重要内容记到「记忆卡」，想继续聊时再接模型服务。

常见疑问

1. 这个工具和官方产品有什么关系？

这不是 DeepSeek 官方软件，也不是几个零散插件的组合方案。技术项目名为 DeepSeek Chat BYOK，是基于官方开源基础代码独立开发的完整 MIT 开源客户端。

2. 我以前从来没听过 API Key，能先用吗？

可以。导入和翻看以前导出的聊天记录、保存重要内容，都不需要填任何 API Key。只有当你希望工具帮你调用在线大模型继续往下写时，才需要在「设置 → 模型与 API」跟着指引贴入一次自己的密钥；每次回答旁边还会直接用通俗人民币估算大概花了多少元。

3. 为什么网页版填对 API Key 仍可能无法聊天？

部分模型接口不允许浏览器直接访问，这是浏览器的跨域限制，不一定是密钥填错。 安卓用户建议下载上方正式 APK；电脑用户可以使用进阶便携版（需要 Node.js 22+）。 在线调用费用由你选择的服务商收取。

4. iPhone 或 iPad 可以使用吗？

目前没有 iOS 安装包，iPhone / iPad 不能安装安卓 APK。 可以先通过 Safari 打开网页版导入和查看旧聊天；在线模型接口仍可能受到浏览器跨域限制。

5. 这个免费开源项目是个人独立维护的吗？

是的。它由开源仓库 kamanager2012/deepseek-chat-byok 独立构建和公开发布；没有自建聊天记录云端账户或会员收费。 本地导入的历史记录保存在当前设备；通过 API 继续对话时，所发送的上下文会由你选择的模型服务商处理。

与官方 deepseek-chat-import 插件、DSH Go / DSH Community 的定位区分

项目 / 工具 定位与适用人群 关键差异
DeepSeek Chat BYOK（本项目） 独立、免费、开源的 BYOK 社区版客户端 基于官方开源 chat-demo 增强，无需安装 Harness，可用自己的 API Key 连接可用模型、保存记忆卡并导回旧记录；网页版需服务商支持浏览器直连。
官方 deepseek-chat-import deepseek-ai/deepseek-harness 里的实验性插件 依赖 Harness 环境运行的实验性插件（支持 CLI 与 Harness 界面），面向已经使用 Harness 工作台的开发者。
DSH Community vs DSH Go 多 Agent Terminal / Harness 工作台与远程控制端 若你需要工程级多 Agent 工具链与远程桌面审批（对应 DSH Go 赛道），见我们独立维护的兄弟仓库 kamanager2012/dsh-community。
