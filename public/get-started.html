费用说明：客户端免费。导入、查看本地历史不需要 API Key；让在线 AI 生成新回复仍需自备密钥，费用由服务商收取。本项目不提供免费模型额度，也不绕过官方限额。

① 不安装，先导入旧对话

支持 DeepSeek、ChatGPT、Claude 官方导出的 ZIP（桌面端可直接拖进页面，安卓可直接在文件管理器点「分享 / 用其他应用打开」）。预览、勾选并保留已有对话合并。

打开网页版（免安装）

历史在当前浏览器本地处理。网页使用共享 GitHub Pages 域名，严格隔离敏感 API Key 的用户建议使用独立安卓或电脑端；清理浏览器站点数据可能删除本地记录。

② 安卓手机：下载正式签名版

选择 android-release.apk，不要下载 debug.apk。按系统提示安装后，可导入 ZIP；需要新回复时再到「设置 → 模型与 API」填 Key。

③ 电脑：下载便携包

Windows / macOS / Linux 可下载 ZIP 解压后直接双击 Start-Windows.bat / Start-macOS.command 启动。便携包仍需本机先装 Node.js 22+ LTS；若只想查看历史，优先用网页版。

第一次使用，只需要三步

  1. 从 DeepSeek 官方导出历史 ZIP，不要将包含隐私的聊天记录交给陌生人。
  2. 在客户端「设置 → 数据管理」导入，选择希望保留的对话。
  3. 如果需要 AI 继续回答，再选择服务商、填写自己的密钥并测试连接。
